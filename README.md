# Лабораторна робота №5

**Тема:** Використання React.js в ASP.NET Core
**Варіант 2:** Бібліотека — каталог книг

## Структура проєкту
- ReactApp — сервер ASP.NET Core Web API
- client — клієнт React.js

## Запуск серверної частини
cd ReactApp
dotnet restore
dotnet run

## Запуск клієнтської частини
В окремому терміналі:
cd client
npm ci
npm run dev

## Адреси
- Сервер: http://localhost:5216
- Клієнт: http://localhost:5173
